# v0.2 development protocol: unattended endogenous cognition

Recorded before implementing the candidate. v0.1 at `9a7945c` is the comparison
baseline; its original evidence must remain untouched. v0.2 uses separate stores
and an explicit runtime selection, never a silent behavioral migration.

## Question and exclusions

After an unresolved situation is supplied once, can changing bodily experience,
unresolved concerns, associative memory activation and prior thoughts create later
cognitive opportunities without another external event? A timer alone, a canned
multi-line story, or a repeated fixed "think again" prompt is not the criterion.

The smallest mechanisms to test are graded projection, accumulated attention to
existing concerns, one-hop spreading activation on existing memory associations,
and a bounded deferred echo of a grounded thought. Semantic interpretation should
resolve a paraphrase/reference against currently available experience, keep doubt
distinct from observation and fail closed for ambiguous referents. General language
understanding is not established by passing a small deterministic semantic grammar.

## Predeclared contrasts

1. Same need grows and recovers: qualitative intensity changes without machine
   telemetry; a graded-projection ablation removes within-threshold progression.
2. Same history, overdue versus resolved commitment, then silence: recurrence
   depends on unresolved evidence, not just elapsed tick count.
3. Same grounded private thought, thought recurrence on/off, then silence: later
   cognitive input carries a parent thought link; finite recurrence must quiesce.
4. Same remembered event and association graph, drift on/off: related but different
   memories can enter later attention with inspectable causal support.
5. A pronoun/paraphrase with one visible referent versus ambiguous or unrelated
   content: interpretation can preserve a supported reference without its literal
   name; an assertion of success cannot resolve a commitment.
6. Independent memory and prospective feedback ablations: disabling autobiographical
   retrieval must not accidentally disable all continuity appraisal, or vice versa.
7. Split-run restart versus uninterrupted continuation: same future state, thoughts,
   triggers and conduct. Workspace, deferred input and exposure budgets persist.

Use more than one actor/wording and include repair, lexical distractors, no
obligation and no new user messages during the unattended window. Compare complete
trajectories, not one selected quotation. Default deterministic generation is a
state-conditioned engineering control and must be reported as such. No claim of
unscripted LLM cognition can be made without actual-model runs on a frozen protocol.

## Acceptance and reporting

Every admitted thought remains private and noncanonical as a world claim. Every
effect has support and bounded exposure; every unattended call has a recorded
trigger. The existing engine remains the only action selector. Record failures,
implementation limits and tuned development cases. These are builder-designed
engineering tests, not independent holdouts or consciousness evidence.
