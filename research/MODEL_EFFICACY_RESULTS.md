# v0.2 model-efficacy status

The frozen model-efficacy-v1 harness is implemented, but no unscripted model run is
recorded here yet. The deterministic v0.2 template experiments remain development
evidence for the recurrence machinery, not evidence about the quality of language
generated by a free model.

The new harness records every synthetic CognitiveView and private output, computes
only provenance-based engineering measures, and replays clean runs from captured
thoughts while verifying the hash of every subjective view. This makes the model's
language separable from the deterministic organism dynamics. A failed replay means
the run is not accepted as a valid closed-loop record.

A live result should not be added to this file until the complete protocol is run
without changing the frozen cases or scoring after inspecting outputs.
